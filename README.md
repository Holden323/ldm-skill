# AI 人味儿汉译汉

**把 AI 写的中文改成人话。**

一个来自 14 年文字老编辑用 AI 辅助写作踩过的无数坑，总结而成的中文去 AI 味方法论。

---

## 这是什么

你用 ChatGPT / Claude / Kimi / 豆包等大模型写了一段中文，总觉得哪里不对——太光滑、太均匀、太"正确"。别人一眼就能看出是 AI 写的。

这个 skill 帮你把 AI 生成的中文改成人话。不是删几个词那么简单，是一套完整的检查+改写流程。

## 解决什么问题

| 问题 | 表现 |
|------|------|
| AI 味太重 | 读者一看就知道是 AI 写的，信任感归零 |
| 句式暴露 | "不是X，而是Y""你以为X，其实Y"满屏都是 |
| 标点断裂 | 每句都用句号断开，读起来像机器人 |
| 词汇书面 | "此外""事实上""值得注意的是"扎堆出现 |
| 内容光滑 | 没有毛边、没有卡顿、没有任何一处是作者自己也没想通的 |

## 实战修改案例

以下案例来自拆书稿（讲书稿）审稿的真实修改，每一条都有原稿和改后对比。

### 案例一："不是…而是"禁令句式泛滥 → 直接说

> 来源：《优秀到不能被忽视》拆书稿审稿，原稿10处"不是A而是B"，每21行出现一次。

```
❌ 原稿：激情从来不是起点，而是结果，是你做出成绩之后，才慢慢滋生出来的东西。
✅ 改后：激情是结果，是你做出成绩之后，才慢慢滋生出来的东西。

❌ 原稿：根本就不是源于激情，始于热爱，他是为了赚钱，过上好日子。
✅ 改后：他是为了赚钱，过上好日子。正是这个简单又俗气的目标，让他一步步扛了下来。

❌ 原稿：真正的职场破局，从来不是一味地向外索取，而是学会向内扎根。
✅ 改后：真正的职场破局，是学会向内扎根。
```

**规则**：保留1处做开篇反转，其余9处删掉"不是"直接说。读者听的是故事，不是辩论。

### 案例二：四个概念罗列 → 一个人物故事蒸出来

> 来源：《松弛感》拆书稿审稿，原稿把"内在力量"拆成四个概念逐个定义。

```
❌ 原稿：
什么是内在力量？它就是一个人作为生命体的内在生命力，主要表现在四个维度上：
内在脚本力、自我对话力、标签破局力和关系赋能力。
内在脚本力，就是你觉得自己有没有价值、够不够好……
自我对话力呢，就是指我们会把别人对待我们的方式，变成自己对待自己的方式……
标签破局力，说的就是一个人突破自己某个标签的能力……
关系赋能力，说的就是我们在跟人交往的时候，是消耗自己的力量，还是通过关系来获得力量。

✅ 改后：
我有个学员叫小林，35岁，互联网公司中层。
她来找我说了一句话："我觉得我随时会被开除。"
我问她业绩怎么样，她说连续两年绩效A。那怕什么？
她说："我也不知道，就是觉得不够好。"
聊深了才发现，她小时候考了98分，她妈问她那2分丢哪了。考了100分，她妈说别骄傲。
这就是内耗的根源——她的身体里住了一个永远在挑刺的声音，
不管外面表现多好，这个声音都关不掉。书里管这个东西叫"内在脚本"。
```

**规则**：一个例子讲清楚，比列四个定义强10倍。听众记住的是小林，不是"内在脚本力"这个词。

### 案例三："所以"做推导 → 换成语调信号

> 来源：《成功，动机与目标》拆书稿审稿，原稿"所以"出现9次，读起来像论文在做推导。

```
❌ 原稿：所以"做到最好"大概率会产生最平庸的结果
✅ 改后：你看，"做到最好"大概率产生最平庸的结果

❌ 原稿：所以乐观本身没问题，关键是分清楚两种乐观
✅ 改后：说白了，乐观本身没问题，关键是分清楚两种乐观

❌ 原文：所以我们面对短期困难任务的时候
✅ 改后：你再想想，面对短期困难任务
```

**规则**：口播稿的段落切换用语调信号（"你看""说白了""你再想想"），不用逻辑连词（"所以""因此"）。"所以"是在推导结论，语调信号是在拉着听众一起走。

## 谁适合用

- **品牌营销**：产品文案、社媒内容需要"人味儿"

## 核心规则速查

| 规则 | 一句话 |
|------|--------|
| 禁令句式 | "不是X，是Y" → 直接说 |
| 句号→逗号 | 后句是前句延续时，用逗号连着 |
| 破折号禁用 | 全部替换为句号或逗号 |
| AI 词汇 | "此外""事实上""本质上" → 删 |
| 广告腔 | "赋能""闭环""抓手" → 全删 |
| 具体画面 | "深层孤独感" → "朋友圈翻了一遍，没找到一个想说话的人" |
| 「你」字克制 | 不要每句都是"你"，改用中性写法 |
| 结尾刺穿 | 描述行为 → 刺穿心理 |
| 三段式 | 能用两个就不用三个 |
