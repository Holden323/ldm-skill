# AI 人味儿汉译汉

**把 AI 写的中文改成人话。**

一个来自 14 年文字老编辑用 AI 辅助写作踩过的无数坑，总结而成的中文去 AI 味方法论。

---

## 这是什么

你用 ChatGPT / Claude / Kimi / 豆包等大模型写了一段中文，总觉得哪里不对——太光滑、太均匀、太"正确"。别人一眼就能看出是 AI 写的。

这个 skill 帮你把 AI 生成的中文改成人话。不是删几个词那么简单，是一套完整的检查+改写流程。

## 解决什么问题

| 问题 | 表现 |
|------|------|
| AI 味太重 | 读者一看就知道是 AI 写的，信任感归零 |
| 句式暴露 | "不是X，而是Y""你以为X，其实Y"满屏都是 |
| 标点断裂 | 每句都用句号断开，读起来像机器人 |
| 词汇书面 | "此外""事实上""值得注意的是"扎堆出现 |
| 内容光滑 | 没有毛边、没有卡顿、没有任何一处是作者自己也没想通的 |

## 怎么用

### 方式一：手动对照（推荐入门）

读 SKILL.md，按 9 个章节逐条检查你的文案：

1. 禁令句式扫描
2. 标点符号检查
3. 数据信源检查
4. 跨选题模板扫描
5. AI 词汇 + 广告腔 + 学术报告扫描
6. 口语化 + 反驳 + 知识堆砌检查
7. 结尾 + 情绪曲线检查
8. 三段式 + 开头检查
9. 对抗性审查（内容逻辑检查）

### 方式二：Agent 自动执行

如果你在用 Hermes Agent 或其他 AI Agent，直接加载这个 skill，让 Agent 按流程帮你过一遍。

### 方式三：Python 脚本扫描（开发中）

自动扫描禁令句式、AI 高频词、破折号、段落长度等机械指标。

## 效果对比

### 禁令句式

```
❌ AI味：你不是不想社交，你是不知道如何社交。
✅ 人味：你刷了一天手机，跟谁说过话？
```

### 标点断裂

```
❌ AI味：你觉得那是乱花钱。但回头看，每一项都指向同一件事。
✅ 人味：你觉得那是乱花钱，但回头看，每一项都指向同一件事。
```

### AI 词汇

```
❌ AI味：此外，值得注意的是，社交APP的普及并没有让人们更亲近。
✅ 人味：社交APP越多，你越孤独。
```

### 抽象 vs 具体

```
❌ AI味：你感到一种深层的孤独感。
✅ 人味：你坐在黑暗里，朋友圈翻了一遍，没找到一个你想说话的人。
```

### 结尾

```
❌ AI味：你手里的笔，现在还在你手里。趁还来得及，看清楚自己到底在写什么。
✅ 人味：（删掉，让故事自己结束）
```

## 谁适合用

- **内容创作者**：用 AI 辅助写文案，但不想让读者看出来
- **品牌营销**：产品文案、社媒内容需要"人味儿"
- **编辑/审稿**：给 AI 写的稿子做质检
- **自媒体运营**：小红书、公众号、抖音口播文案
- **任何写中文的人**：只要你想让文字更像人说的话

## 核心规则速查

| 规则 | 一句话 |
|------|--------|
| 禁令句式 | "不是X，是Y" → 直接说 |
| 句号→逗号 | 后句是前句延续时，用逗号连着 |
| 破折号禁用 | 全部替换为句号或逗号 |
| AI 词汇 | "此外""事实上""本质上" → 删 |
| 广告腔 | "赋能""闭环""抓手" → 全删 |
| 具体画面 | "深层孤独感" → "朋友圈翻了一遍，没找到一个想说话的人" |
| 「你」字克制 | 不要每句都是"你"，改用中性写法 |
| 结尾刺穿 | 描述行为 → 刺穿心理 |
| 三段式 | 能用两个就不用三个 |
