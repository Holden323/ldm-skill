# 会话交接格式

完整交接时使用；用户只要单项产物时只采用对应部分。

## 保存结构

```text
<存档根目录>/<YYYY-MM-DD>/
├── <YYYY-MM-DD>_对话全记录_<平台>_<主题>.md
└── <YYYY-MM-DD>_路由器_<平台>_<主题>.md
```

文件名中的主题应短、可辨认，不包含密钥或私人标识。报告时使用绝对路径。

## 对话全记录文件头

```markdown
# 对话全记录

> 平台：<平台>
> 会话标识：<session id 或源文件标识>
> 起止时间：<开始> ~ <结束或进行中>
> 消息数：<数量与过滤说明>
> 导出时间：<时间>
> 导出方式：<原生导出 / SQLite 直读 / JSONL 直读>，非 AI 摘要
> 截断：<无；或阈值与条数>
```

正文按 `## 用户`、`## 助手` 交替记录。不要混入工具输出。

## 路由器

路由器是恢复上下文的主力，重启提示语只是入口。原文负责回查，路由器负责恢复。

```markdown
# <日期> <主题> — 路由器

> 平台与会话：<标识>
> 时间：<范围>

## 关键决策

- <决定、理由、仍适用的边界>

## 存档点

> 按时间顺序，只写做完并确认过的关卡；没验证的不算。

1. <关卡> —— 凭据：<绝对路径 / 链接 / 验证结果>

## 产出清单

| 产物 | 绝对路径或最终链接 | 状态 |
|---|---|---|

## 资源版本

> 只写「新会话用错版本就会做错」的东西。还没定的状态、还没做的事，写进待办或下一步，不要放这里。没有就写「无」。

- <skill / 素材库 / 模板 / 工具>：<版本或快照标识>（<当前有效 / 已被哪版取代>）

## 当前进度与下一步

- 进行中：<已经开始但没做完的事；没有写「无」>
- 下一步：<具体的下一个动作与完成条件>
- 前置条件：<动手之前必须先具备或确认的东西；没有写「无」>

## 待办

- <具体任务、数量或完成条件>

## 经验教训

- <只写本次新增且可复用的内容>
```

## 重启提示语

```text
继续<任务>。

上次已完成：
- <产物与状态>

接下来：
- <下一步与完成条件>

先读这些文件恢复上下文（进度、资源版本和前置条件以路由器为准）：
- <路由器绝对路径>
- <需要时再读的原文或关键产物绝对路径>

约束：
- <仍然有效的关键限制>
```

提示语是入口不是主力：让下一会话无需重新搜索即可找到路由器，但不要把整份路由器复制进去。
